# Fonts

`monogram.ttf`: **monogram** by datagoblin (Vinícius Menézio), version 1.1.0, from https://datagoblin.itch.io/monogram. Released under **CC0 1.0 Universal** (public domain); no attribution required, credited here anyway.

Used for the controls only (`--font-pixel` in `style.css`). It is drawn on a 16-units-per-em pixel grid (6 px advance, 7 px cap height), so keep it at multiples of 16px; 32px is crisp at 1×, 2× and 3× device pixel ratios.
